# Invigilator Assignment Optimization

Multi-objective CP-SAT optimization model for university exam invigilator assignment scheduling.

## Features

- CP-SAT optimization using OR-Tools
- Multi-objective scheduling
- Workload fairness
- Fatigue reduction
- Cross-campus travel minimization
- Solver audit report
- Alpha-weight sensitivity analysis
- Genetic algorithm extension

## Technologies

- Python
- OR-Tools
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
